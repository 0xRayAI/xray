# Suit

Give your agent a suit. The rules stay on, you add powers, and it runs in the tool you already open.

```
  ┌────────────────────────────────────────────────────────────┐
  │ SUIT · what it wears                                       │
  ├────────────────────────────────────────────────────────────┤
  │ · the rules stay on                                        │
  │ · you put it on once                                       │
  │ · it builds the foundries                                  │
  └────────────────────────────────────────────────────────────┘
                                │
                          you add powers
                                v
  ┌────────────────────────────────────────────────────────────┐
  │ WHERE IT RUNS                                              │
  ├────────────────────────────────────────────────────────────┤
  │ · the tool you already open                                │
  │ · grok-bot · Hermes · OpenCode                             │
  │ · OpenClaw · Grok CLI · Cursor                             │
  └────────────────────────────────────────────────────────────┘
                                │
                           they snap on
                                v
  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
  │ REPERTOIRE       │  │ DYNAMO           │  │ CLEARING         │
  │ · memory         │  │ · judgment       │  │ · payments       │
  └──────────────────┘  └──────────────────┘  └──────────────────┘
  
    goggles views one plane
```

A foundry is mills and hangars. The mill builds and ships. The hangar is the shop. Same rules in the repo. You are not locked into one app.

While Bifrost health says the board is live, worn Grok hooks send a turn, an issue tag, a pull tag, and a handoff packet. A quiet board sends nothing. When Bifrost is on, the only TUI monitor is `house/live/tools/inbox-watch.sh`.
