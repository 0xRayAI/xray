Five pages: station card `.xray/state/STATION.md`, notes `.xray/state/NOTES.md`, a plate `docs-site/docs/plates/<id>.md`, the lens page for one plane, a reflection `docs/reflections/`.

Package face: `README.md`, `package.json`, `AGENTS.md`, `llms.txt`, `CHANGELOG.md`, `SKILLS.md`, and each `SKILL.md`.

Trail: state and logs under `.xray`. Codex is already loaded. This plate is the file ref.

The published manual is `docs-site/docs/`. The rule sheet is `grok-bot/OP-PROC.md`. Neither is one of the five pages.
