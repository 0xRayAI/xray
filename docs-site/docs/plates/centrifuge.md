# Centrifuge

One wake is one turn. Station is the axle. The gap stays open.

```
                         CENTRIFUGE
                    ┌──── VISOR ────┐
                    │    GOGGLES    │
                    └───────┬───────┘
                            │ looks down
         ┌──────────────────┴──────────────────┐
         │               DOMAIN                │
         │                                     │
JUDGEMENT│   LOOP                   STATE      │PAYMENTS
 · off   │            STATION                  │ · off
 · fixed │                          FOUNDRY    │ · fixed
         │               MEMORY                │
         └────────────── ONE TURN ─────────────┘
                    the gap stays open
```

Loop, domain, state, foundry, and memory ride that turn. Judgement and payments stay off the rotor. Goggles looks on and does not spin. The next turn waits for the next session or compact.
