# Governance

A proposal is deliberated inside the suit, filtered by Dynamo Solar, then merged. The PreToolUse codex gate stands beside the vote.

```
┌────────────────────────────────────────────────────────────┐
│ INPUT LAYER                                                │
│                                                            │
│   ┌────────────────────────────────────────────────────┐  │
│   │ proposal                                           │  │
│   │ title · description · type                         │  │
│   └──────────────────────────┬─────────────────────────┘  │
└──────────────────────────────┼────────────────────────────┘
                               v
┌──────────────────────────────┼────────────────────────────┐
│ PROCESSING LAYER             v                            │
│   ┌────────────────────────────────────────────────────┐  │
│   │ internal deliberation                              │  │
│   │ code-review · security-audit · researcher          │  │
│   └──────────────────────────┬─────────────────────────┘  │
│                              v                            │
│   ┌────────────────────────────────────────────────────┐  │
│   │ external filter                                    │  │
│   │ Dynamo Solar SSOT                                  │  │
│   └──────────────────────────┬─────────────────────────┘  │
│                              v                            │
│   ┌────────────────────────────────────────────────────┐  │
│   │ merge                                              │  │
│   │ governance-core weighted vote · decision matrix    │  │
│   └──────────────────────────┬─────────────────────────┘  │
│                              │                            │
│   ┌──────────────────────────┼─────────────────────────┐  │
│   │ PreToolUse gate          │                         │  │
│   │ Codex 11 · 29 · 69       │  beside the vote        │  │
│   └──────────────────────────┼─────────────────────────┘  │
└──────────────────────────────┼────────────────────────────┘
                               v
┌──────────────────────────────┼────────────────────────────┐
│ OUTPUT LAYER                 v                            │
│   ┌──────────────────────┐      ┌──────────────────────┐ │
│   │ vote                 │      │ codex decision       │ │
│   │ approve / reject     │      │ allow / deny         │ │
│   └──────────────────────┘      └──────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```
