# Goggles

It views one plane. Not every plane at once.

```
  ┌──────────────────────────────┐     ┌──────────────────────────────┐     ┌──────────────────────────────┐
  │ LENS                         │     │ ONE PLANE                    │     │ OUT OF FRAME                 │
  ├──────────────────────────────┤     ├──────────────────────────────┤     ├──────────────────────────────┤
  │ · you look through it        │     │ · the one you name           │     │ · every other plane          │
  │ · empty until you look       │     │ · one view                   │     │ · still there                │
  │ · not a power                │     │ · what is in front of you    │     │ · not this look              │
  └──────────────────────────────┘     └──────────────────────────────┘     └──────────────────────────────┘

  ┌────────────────────────────────────────────────────────────┐
  │ THE TAKE                                                   │
  ├────────────────────────────────────────────────────────────┤
  │ · a short read of that plane                               │
  │ · at most one move                                         │
  │ · tune, fix, or a new power                                │
  └────────────────────────────────────────────────────────────┘

  one plane in the frame. the others stay out.
```
