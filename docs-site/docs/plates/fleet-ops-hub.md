# Fleet Ops Hub

Running many agents like one team.

```
┌────────────────┐     ┌────────────────┐     ┌────────────────┐     ┌────────────────┐     ┌────────────────┐
│ORCHESTRATION   │ ─── │RELIABILITY     │ ─── │GOVERNANCE      │ ─── │SPEND           │ ─── │GUIDES          │
│who owns the    │     │wakes, retries  │     │review gates    │     │compute you     │     │CONSULT         │
│card, who's     │     │no silent       │     │before merge    │     │can defend      │     │ops.0xray.dev   │
│next            │     │stalls          │     │or publish      │     │                │     │                │
└────────────────┘     └────────────────┘     └────────────────┘     └────────────────┘     └────────────────┘
                                                                                                              
ops.0xray.dev · consult@0xray.dev                                                                             
```

One team means one owner on the card, a review before merge or publish, and spend a person can defend. Agents execute and prove. Humans approve money, public posts, and credentials (`grok-bot/ops/OPS-SPEC.md:8`). The build publishes the artifact (`grok-bot/ops/OPS-SPEC.md:17`).

Who does which job is a separate plate (`docs-site/docs/plates/fleet.md`).

Write consult@0xray.dev. The ops site is https://ops.0xray.dev.
