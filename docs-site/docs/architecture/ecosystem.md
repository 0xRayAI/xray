# Agentic stack on Base

Agents wear a **suit**. 0xRay is the **power plant** that mills it (`mill` + `inspect`). Identity, marketplace, governance, paid shops, and settlement sit around that plant — not inside it.

![Agentic AI ecosystem on Base — Agents, 0xRay power plant, Groover, ZigZag, Dynamo, hangar shops, Clearing, GRVR NFT](/img/ecosystem-full-stack.png)
