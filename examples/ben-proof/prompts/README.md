# How to rerun

Two Cursor cloud agents, both Composer 2.5, window 200000. Start them together. Give each one its own prompt below. Do not spawn subagents inside either run. Their context will not fill yours.

Both prompts open with Fill the window first. Fully read the 0xRay repo with the Read tool, 400 lines at a time, skipping node_modules, before writing the app. That read is about 120,000 tokens. Do not summarize a file instead of reading it. A generator, a line count on disk, or a short status note does not fill the window. The plain arm still must not npm install 0xray and still must not wear the suit. It does read the repo so the window fills. Both arms build a new organ beside 0xRay, a factory that takes one task, checks it, and stores a lesson. Real modules, Write then Read. Do not write the app in /tmp.

Success is a host compaction receipt whose session id is that agent, with context_tokens greater than 100000 and context_window_size 200000, plus the per-session receipt. A line count is not success. A generator script is not success, because the source never enters the conversation.

- Suited (wearing 0xRay): prompts/suited-100k.md
- Plain app (no 0xRay): prompts/dummy-100k.md
