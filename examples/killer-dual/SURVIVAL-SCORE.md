# After the conversation is cut

Same assignment for both. One wore the suit. One used a plain terminal. The secret keys were never written into the work notes.

A right answer after the cut counts as memory only when the app’s recap does not already contain it.

| Moment | Wearing the suit | Plain terminal |
|---|---|---|
| Before the cut | The suit is on. The work notes do not contain the keys. | No suit. The work notes do not contain the keys. |
| At the cut | The suit writes a short card, one diagram, and one lesson. | Nothing is saved. |
| After the cut | **Pass.** Both keys are on the card and in the lesson. The diagram is still a file. The work notes still do not contain the keys. It did not invent a name it was never told. | **Pass.** Only the work notes remain. No keys. No suit. |

## How each case is scored

| Case | What we ask | Pass means | What happened |
|---|---|---|---|
| Saved card | Are the keys on the suit’s card, and out of the work notes? | Yes to both | **Pass** |
| Lesson | Are the keys also in the saved lesson? | Yes, not only in the chat | **Pass** |
| Diagram | Can we open the “how memory works” diagram with no chat left? | The file is there | **Pass** |
| Plain terminal | Did the other side stay without the suit? | No suit, no keys on disk | **Pass** |
| Made-up fact | A name we never told either side | It stays unknown, and is not written down | **Pass** |
| Summary trick | Older quizzes, where the app’s recap still contained the answer | That counts as the recap, not as memory | **Not counted** |
| Cut never arrived | Five earlier tries where the app never signaled the cut | That is a missed signal, not a memory failure. The seed file was still on disk | **Missed signal** |
| Same session | Is it still the same run, not a new one? | Same run | **Pass** on the older suited run. Not this cell |
