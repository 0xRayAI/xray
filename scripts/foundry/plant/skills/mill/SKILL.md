# Mill

The mill **fastens** their plant onto the hanger. It does not copy the 0xRay 45-skill / 42-agent costume unless they opt in.

**Plant (their SSOT):** `xray/codex.json`, `xray/features.json`, `xray/config.json`, `src/skills/<name>/SKILL.md`, `src/opencode/agents/*.yml`. Remap with `foundry.json`.

**Mill-fill:** their keys/files win. Mill mill mill-fill mill names they did not plant stay. JSON always merges.

**Factory:** Repertoire organ enable-when-resolves. Seven generated MCP. Constitution (PPE) stays worn. Not a fifth MCP. Not 5.0.

**Costume:** `foundry.json` `"costume": true` copies the 45/42 mill garment. Default is empty garment + this mill mill-fill mill plant.

```bash
npx @0xray/foundry mint
```

Nested mill: `node node_modules/0xray/scripts/foundry/cli.js mint`.
