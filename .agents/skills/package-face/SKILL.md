# package-face

The file a release owns first is `package.json`.

The face is `README.md`, `package.json`, `AGENTS.md`, `Agents.md`, `AGENTS-consumer.md`, `llms.txt`, `CHANGELOG.md`, `SKILLS.md`, and `CLAUDE.md`. A release writes these. The agent reads them. Do not hand-bump the version. The plates that stay with this lens are record-map and suit-wear.
