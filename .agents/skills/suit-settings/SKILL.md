# suit-settings

The package copy is `xray/features.json`. There is no settings.json.

Settings are `.xray/features.json`, `.xray/config.json`, `.xray/codex.json`, and `.mcp.json`. Wear writes the consumer copies. The package copies live under `xray/`. The plates that stay with this lens are suit-wear and record-map.
