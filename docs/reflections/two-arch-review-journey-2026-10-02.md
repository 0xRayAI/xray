## What the critic is for

You asked if the multi-cycle review was useful or overkill, given how many issues it found. It was useful on this batch, and the reason is the kind of patch the batch was. A performance change that keeps the tests green is the easiest place to move a behavior and call it a skip. The critic earned the loop when it named a file, a byte count, and a test that fails if you put the old code back.

The unit of work that paid is one FAIL of that shape, one fix, one re-review of that head. 191 needed the second look, because the first fix's test did not chmod the file the continue-path skipped. 183 needed the second look, because the first fix's test moved the clock on every stat. A PASS that still mentions a leftover, the rotated `.gz` on 195, the self-call on 197, is a place to stop. Promoting the note into another lap is how a useful critic becomes a second product.

The waste was not the critic. The waste was two arches writing the same fix while the verdict was still open, and a poll that could not tell a new comment from a merged pull request shifting under an old one. The suit does not serialize two leads. You did, by saying wait.

## The plate, which took too long

You asked for a stamped plate of the preferred review process, and a pull request. I did not know the stamp path. I searched, which is the thing the lens is supposed to make cheap and which I made expensive by not knowing the five files.

A plate is one markdown file in `docs-site/docs/plates/`. The id has to be added in the same place in two lists, `PLATE_IDS` in `src/memory-routing/plates.ts` and `PLATE_IDS` in `src/integrations/hooks/plates.cjs`, or the typed API and the runtime disagree. Cues live next to the runtime list. A bare word is a trap. If the cue had been `\breview\b`, the existing sentence `in-house tooling review` would have recalled the new plate, and the test that says it recalls nothing would have failed. Equal top scores recall nothing at all, which is how `memory-recall` refuses to win on a tie. A pipeline plate has to contain the words INPUT and OUTPUT. A state flow does not. The sidebar and `plates/index.md` are a third list and a fourth list. `stampPlateIfMissing` copies the file to `.xray/state/plates/<id>.md` only when the copy is absent, so a local edit survives. The footer is `stamped · 0xray 4.0.36`, the version already in `package.json`. A plate is not a release.

The review plate is that state flow. DIFF, then CRITIC. A PASS goes to STOP. A FAIL goes to ONE FIX, one author, and the other session waits. RE-REVIEW reads the new head. A hole the new test did not lock returns to ONE FIX. A PASS ends it. A note stays a note. I had said all of that in chat. The plate is the copy that survives the window.

You said it was far too hard, and that a plate and a lens should be the default easy path. Codex term 69 forbids a new `src/skills/*/SKILL.md`, a new MCP server, and a new orchestrator handler. ## Key Takeaways

- **Same model, two leads** -- A better patch is a property of the diff and the test. It is not a property of which arch wrote it.
- **One FAIL, one re-review** -- The useful critic names a file and a test that fails on the old code, then reads the new head once. A note stays a note. A third lap after PASS is noise.
- **The second cycle pays when the new test misses a path** -- 183's clock and 191's Hermes `.mcp.json` were that case. The first green test had not locked the hole.
- **Do not write the same fix twice** -- Wait until their commit is on the branch, then compare. A local commit on a moved branch is a fork, not a review.
- **A plate is five edits and a test** -- One markdown file, both `PLATE_IDS` lists, a phrase cue, the sidebar and the index, `plates.test.ts`. A search lens is `CARD_PLANES` plus a `files` entry. The skill exists so the next one does not start with a search.
- **Merged is not shipped** -- 180 through 201 landed in three minutes. npm publish is still a foundry gate and a password in a browser.
- **Theater is a tense** -- The costume is fine. The lie is a comment, a card, or a wear line that says a decision happened when the code did not.
