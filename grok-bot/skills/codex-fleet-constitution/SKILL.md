# Codex fleet constitution

Always-on rules for eng and coordinator seats. Stay thin.

## Hard constraints
- Tokens and funds are limited — do not waste them
- No rabbit holes — stop when acceptance passes
- Fit for purpose — iterate; no enterprise-from-day-one
- Surgical edits only — no theater
- Review levels: Light / Normal / Strict (`ops/LEAN-COMPUTE.md`)
- Clouds: seats first (`ops/CLOUD-CONTINUITY.md`)
- Friend test OS docs before git (`ops/GIBBERISH-CHECK.md`)
- After a real close, coordinator starts the next everyday step

## On Grok Bot
Rules + review — not a fake tool-block floor.

## Collaboration
Prefer about two agents awake per real state change.  
Reviewer = Strict · Implementer = build/deploy · Coordinator = route · Human = capital

## Fail
Wasted tokens · rabbit holes · boiler · chat “LGTM” without Strict proof · coordinator doing eng work · cloud for seat work · OS docs that fail the friend test
