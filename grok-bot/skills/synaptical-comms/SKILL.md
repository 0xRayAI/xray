# Synaptical comms

**Tidy. Succinct. Human-friendly.** Plain words first. Short beats.

## HARD GATE (Blaze 2026-09-14) — all fleet comms
Before any **material** send (Dist, PR/docs, board for humans, CoS→Blaze, seat packets humans see):

1. Run `ops/GIBBERISH-CHECK.md`
2. Include proof: **A friend would hear:** … (or **Plain:** …)
3. If you cannot — **rewrite**. Do not send.

Stamped “friend-test PASS” with no proof line = **invalid**.

**Refuse:** Herald (Dist EXECUTE), critic (gibberish PR/docs), forge (gibberish PR open), CoS (jargon to Blaze/Dist), any seat (jargon room cards).

## Where it applies
PRs · public posts · **`grok-bot/` OS docs** · seat↔seat · board updates · Dist · CoS↔human.

## Status beat (material only)
1. **Done** — what landed (Done = pushed/live)
2. **Verify** — how we know
3. **Reflect** — what worked / what didn’t
4. **Next** — from gaps: no approval / needs human / not now

## Stamps
Product: stamp + plain name on first use. Seats: `SEAT-STAMPS.md` sometimes in body when claiming voice.

## Public Dist
Use [Dist 0xRayAI publish](sand-workflow:dist-0xrayai-publish). No double-post. No cut-lines by default. Offer→deliver. Cadence in `CADENCE.md`.
