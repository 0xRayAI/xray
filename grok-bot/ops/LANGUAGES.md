# Languages of the op model

How the fleet speaks. Not products. Add rows as we invent them.

## Speaking lanes (audience)

| Name | Also called | Audience | Style | When |
|------|-------------|----------|-------|------|
| **Lane H** | human / public | Blaze, Dist/X, public PRs/docs, board needing a human | Plain English. Friend-test. Proof: “A friend would hear: …” | Default for anything a stranger or Blaze must act on |
| **Lane B** | bot internal | seat↔seat (eng/dist/ops) | Compressed synaptical — stamp · Done · Verify · Next · ids | Token-save; escalate to H if human must act |

## Kernels (how compression works)

| Name | Plain | Notes |
|------|-------|-------|
| **Meaningful Compression** | Cut words, keep meaning | Upstream idea / house kernel |
| **synaptical** / **synaptical concurrency** | Fleet house style of Meaningful Compression | Dense beats; not an excuse for Dist gibberish |
| **Friend-test** | Would a sharp friend get it in ~3s? | Hard gate on Lane H (`GIBBERISH-CHECK.md`) |

## Artifact dialects (what the text is for)

| Name | Plain | Typical surface |
|------|-------|-----------------|
| **Dist voice** | Public product talk on @0xRayAI | CHARTER / VOICE / CADENCE |
| **Shop receipt** | Short proof a card closed | critic PASS card, npm view, Dist URL |
| **Board beat** | Done → Verify → Reflect → Next | WAVEBOARD / CoS status |
| **Card** | One ticket to one seat | assign text + acceptance |
| **PR digest** | Why this change / how to check | PR body (Lane H) |
| **Hook / plant talk** | Suit · mill · PreToolUse · Station | Eng docs — always gloss on H |

## Do not confuse

| Pair | Diff |
|------|------|
| Lane B ≠ Dist voice | Internal density ≠ public posts |
| synaptical ≠ friend-test fail | Compression must still glimpse-read on H |
| stamp ≠ product | Seat mark ≠ stack SKU |
| receipt ≠ chat LGTM | Proof ≠ vibes |
