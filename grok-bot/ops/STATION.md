## Seat station

A seat's station is the `.xray/state/STATION.md` the 0xray suit installs at the project root (latest wear). On wake: confirm you wear the latest 0xray suit (re-wear via forge if behind), then read that station; update it at the end of each wave. It holds never keys, tokens or PEM text, only where a secret lives (its env var name).
