# Synaptical lanes — H vs B (internal language)

**For kit users:** two speaking styles in this fleet.

| Lane | Who hears it | Style |
|------|----------------|-------|
| **H — Human / public** | People, Dist/X, public PRs/docs | Plain English. Friend-test. Proof line: “A friend would hear: …” |
| **B — Bot internal** | Seats talking to seats | Compressed **synaptical** shorthand — seat stamp · Done · Verify · Next · ids. Saves tokens. Quiet on “already known” acks. |

**Rule:** if a human must act, use **H**. Never post Dist in B.

**Kernel:** Meaningful Compression / synaptical concurrency (house style). Friend-test SSOT: `GIBBERISH-CHECK.md`.

**Seat stamps:** `ops/dist/brand/SEAT-STAMPS.md` (blinky 🖲️ · forge 🔨 · …).

## CloudAgent / external workers
Always **Lane H**. Lane B never crosses into cloud launch prompts.
