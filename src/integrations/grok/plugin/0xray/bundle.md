# Bundle

Lots of small cards stay. A same-path cluster is one tip and one pull. The body lists `Closes #A #B`. Critic Strict is once on that head. R opens the bundled pull. A tips the cluster only and does not open the pull. A blocker hotfix, a different deploy surface, an unrelated acceptance, or a soft follow-up stays its own tip. An open solo tip stays solo unless Arch1 widens a same-path bundle on purpose. There is no retro pass.

Escalator: in a wave, one pull at a time means one Railway deploy and one CI wait. A same-path cluster is one tip, one pull, one Strict, and one deploy. Prefer that over serial deploys.

The suit reads this file from the worn plugin. It does not restate the rule in a skill or in AGENTS.
